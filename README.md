# stwebsite

Portfolio site for Sachi, deployed with GitHub Pages.

## How to edit

Edit `dist/content.json` in GitHub. That file controls the visible text, contact info, project titles, project links, and image URLs.

After committing a change, GitHub Pages redeploys automatically. The live site updates in about a minute:

https://infoshubhjain.github.io/stwebsite/

## What not to edit

Leave `dist/index.html` and `dist/app.js` alone unless you want to change the design or behavior.

## Small easter eggs

Click the Illinois logo three times for watershed mode. Type `ILLINI` on the page for a short Illinois highlight.
